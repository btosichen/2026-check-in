# Google 表單＋試算表報到系統

1. 建立 Google 表單，題目名稱請使用：`姓名`、`身分`、`Email`。身分使用單選題，選項為「教師、職員」。
2. 在表單的「回覆」頁連結到新的 Google 試算表。
3. 開啟試算表的「擴充功能 → Apps Script」，貼上 `Code.gs` 全部內容並儲存。
4. 回到試算表並重新整理，點「報到系統 → 初始化工作表」。
5. 在黃色欄位填入活動名稱、日期、開始／截止時間、表單 ID 與公開網址。
6. 執行 `installFormSubmitTrigger` 一次並完成 Google 授權。
7. 點「報到系統 → 套用時間並建立觸發器」。修改時間後再按一次即可更新。

## 表單 ID 在哪裡

編輯網址通常是 `https://docs.google.com/forms/d/表單ID/edit`，中間那段就是表單 ID。

## 注意

- Apps Script 的定時觸發器可能在設定分鐘附近執行，通常不是精確到秒。
- 如果學校有 Google Workspace，建議再於表單設定中開啟「限制為校內帳號」與「每人僅能回覆一次」。
- QR Code 使用 QuickChart 產生，若校網阻擋該服務，可改用下載後的固定 QR 圖片。
